# 📘 Course 2: Get Started with Python

This folder contains all the materials and deliverables for **Course 2: Python for Data Analytics**, the second course in the **Google Advanced Data Analytics Certificate** program.

---

## 📌 Course Overview

This course focuses on the **Python programming language**, a powerful tool essential for data analysis. You will learn the fundamental concepts of Python programming and understand how data professionals leverage Python in their day-to-day work.

Key concepts covered include:

- **Object-oriented programming**
- **Variables and data types**
- **Functions**
- **Conditional statements**
- **Loops**
- **Data structures**

Experienced Google employees working in the field will guide you through this course, providing hands-on activities that simulate relevant tasks, sharing practical examples, and helping you enhance your data analytics skills for your career.

---

## 📁 Folder Contents

This repository is structured to reflect the course's practical components:

### `Ungraded_Labs/`
This folder contains **Jupyter notebooks** and other relevant files for hands-on exercises and practice activities. These labs are designed to reinforce concepts and build practical coding skills across the course modules.

### `Case_Study/`
This folder includes the key deliverables for the course’s main project or case study, typically including:

- **Jupyter Notebook(s)**: Containing the detailed data analysis, Python code, and insights derived from the case study.
- **Strategy Document**: Outlining the analytical approach, key findings, and strategic recommendations based on the data.
- **Executive Summary**: A concise, high-level overview of the case study's purpose, methodology, key results, and actionable insights—designed for stakeholders.
