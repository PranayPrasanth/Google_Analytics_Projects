# 📘 Course 6: The Nuts and Bolts of Machine Learning

This folder contains all the materials and deliverables for **Course 6: Machine Learning – Advanced Techniques**, the sixth course in the **Google Advanced Data Analytics Certificate** program.

---

## 📌 Course Overview

This course introduces you to **machine learning (ML)**—a powerful field that uses algorithms and statistics to discover patterns in data. You will learn how data professionals apply machine learning to:

- Analyze large volumes of data
- Solve complex problems
- Make accurate predictions

The course focuses on the two primary types of machine learning:

- **Supervised learning**
- **Unsupervised learning**

You’ll also gain practical experience applying ML models to business problems, with exposure to models such as:

- **Naive Bayes**
- **Decision tree**
- **Random forest**
- **XGBoost**, and more

This course includes **5 modules**, guided by experienced Google employees through real-world tasks and examples.

---

## 📁 Folder Contents

This repository is organized to reflect the course's practical components:

### `Ungraded_Labs/`
Contains **Jupyter notebooks** and resources for hands-on practice, reinforcing machine learning concepts and techniques using Python.

### `Case_Study/`
Includes the primary project deliverables, typically:

- **Jupyter Notebook(s)**: Featuring detailed ML analysis, Python code, and derived insights.
- **Strategy Document**: Describes the approach, key findings, and recommendations based on machine learning models.
- **Executive Summary**: A high-level overview of the project’s objectives, methodology, results, and actionable insights for stakeholders.
