# 📘 Course 5: Regression Analysis – Simplify Complex Data Relationships

This folder contains all the materials and deliverables for **Course 5: Regression Analysis: Predicting Numerical Outcomes**, the fifth course in the **Google Advanced Data Analytics Certificate** program.

---

## 📌 Course Overview

In this course, you will learn how data professionals leverage **regression analysis** to uncover relationships between variables and identify key factors influencing business performance.

You'll gain practical experience in:

- Modeling variable relationships
- Exploring various data modeling methods
- Applying models to solve real-world business problems

Topics covered include:

- **Linear regression**
- **Analysis of variance (ANOVA)**
- **Logistic regression**

Experienced Google employees guide you through hands-on activities, simulate real-world scenarios, and share insights to help you develop valuable data analytics skills.

---

## 📁 Folder Contents

This repository is structured to reflect the course's practical components:

### `Ungraded_Labs/`
This folder includes **Jupyter notebooks** and relevant files for hands-on practice exercises, helping reinforce regression analysis concepts and build applied skills.

### `Case_Study/`
This folder contains the main deliverables for the course’s project or case study, including:

- **Jupyter Notebook(s)**: Featuring detailed regression analysis, Python code, and insights.
- **Strategy Document**: Describes the analytical approach, key findings, and strategic recommendations.
- **Executive Summary**: Provides a high-level overview of the project’s purpose, methodology, key results, and actionable insights—tailored for stakeholders.

## 💡 Skills Gained

Upon completing this course, I have developed and enhanced the following skills:

- **Predictive Modeling & Correlation**: Explored how predictive models describe variable relationships, focusing on correlation.
- **Multiple Regression**: Learned how multiple regression builds upon simple linear regression at each step of the modeling process.
- **ANOVA Testing**: Executed and interpreted one-way and two-way ANOVA tests.
- **Logistic Regression Models**: Constructed various logistic regression models including:
  - **Binomial**
  - **Multinomial**
  - **Ordinal**
  - **Poisson log-linear regression**
