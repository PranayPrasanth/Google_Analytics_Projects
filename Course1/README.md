# Course 1: Foundations of Data Science

This folder contains all the materials and deliverables for **Course 1: Foundations of Data Science**, the first course in the Google Advanced Data Analytics Certificate program.

---

## Course Overview

This introductory course explores the multifaceted role of data professionals in today's workplace. It delves into how data professionals help businesses make informed decisions by leveraging powerful techniques such as **data storytelling, statistics, and machine learning**. You'll also be introduced to the **PACE (Plan, Analyze, Construct, Execute)** project workflow—a structured approach to organizing and managing data projects effectively.

Throughout the course, experienced Google employees guide you through practical, hands-on activities that simulate real-world tasks, share insights from their daily work, and help you refine your data analytics skills, preparing you for a successful career.

---

## Folder Contents

This repository is structured to reflect the course's practical components:

### Case_Study/

This folder holds the key deliverables for the course's main case study. It typically includes:

- **Strategy Document:** Outlining the analytical approach, key findings, and strategic recommendations based on the data.  
- **Project Proposal:** Detailing the scope, objectives, methodology, and expected outcomes of the project.
