# 📘 Course 3: Go Beyond the Numbers – Translate Data into Insights

This folder contains all the materials and deliverables for **Course 3: Data Storytelling and Visualization**, the third course in the **Google Advanced Data Analytics Certificate** program.

---

## 📌 Course Overview

This course focuses on the critical skill of **data storytelling** – finding the narrative within data and communicating it in a compelling manner. You will discover how data professionals use storytelling to gain deeper insights and effectively convey key findings to teammates and stakeholders.

The course emphasizes practical application through:

- **Exploratory data analysis (EDA)**
- **Creation of impactful data visualizations**

Experienced Google employees working in the field guide you through hands-on activities, share practical examples, and help you build your data analytics and visualization skills.

---

## 📁 Folder Contents

This repository is structured to reflect the course's practical components:

### `Ungraded_Labs/`
This folder contains **Jupyter notebooks** and other relevant files for hands-on exercises and practice activities. These labs cover topics taught throughout the course and help reinforce coding and visualization concepts.

### `Case_Study/`
This folder holds the main deliverables for the course's case study, including:

- **Jupyter Notebook(s)**: Containing detailed data analysis, Python code, visualizations, and insights.
- **Strategy Document**: Describes the analytical approach, key findings, and strategic recommendations.
- **Executive Summary**: A high-level overview of the project’s purpose, methodology, results, and actionable insights, designed for stakeholders.
